Subir a GitHub Pages y Compartir

Este juego está contenido en un solo archivo HTML sin imágenes externas, ideal para subirlo gratis a GitHub Pages y mandar el link a tus amigos:

  1. Guarda este código en tu PC con el nombre exacto index.html.
  2. Entra a github.com, crea un repositorio público nuevo (por ejemplo: torneo-sumo) y sube el archivo index.html.
  3. Dentro del repositorio, ve a Settings → sección Pages (columna izquierda).
  4. En Branch elige main y presiona Save.
  5. En 1 minuto GitHub te dará tu link https://tu-usuario.github.io/torneo-sumo/ listo para compartir.
